# Excel MIS Reporting Dashboard

## Project Overview

This project focuses on analysing sales performance and developing a Management Information System (MIS) reporting dashboard using Microsoft Excel.

The objective is to transform raw sales data into meaningful business insights through data cleaning, Excel formulas, PivotTables, and interactive visualisations.

## Business Objectives

- Analyse overall sales performance.
- Compare sales across regions and product categories.
- Evaluate salesperson performance.
- Identify monthly sales trends.
- Build an interactive dashboard to support business decisions.

## Tools & Techniques

- Microsoft Excel
- Data Cleaning and Validation
- Excel Formulas and Functions
- Lookup Functions
- PivotTables and PivotCharts
- Conditional Formatting
- Power Query
- Interactive Dashboard Design

## Key Performance Indicators (KPIs)

- Total Net Sales
- Completed Orders
- Total Units Sold
- Average Order Value
- Regional Sales Performance
- Product Category Performance
- Salesperson Performance
